# 📚 Tarea 3 - Java Collections

## 📝 Descripción

Repositorio de ejercicios de Java centrados en el uso y la manipulación de colecciones mediante el **Java Collections Framework**.

A través de diferentes prácticas se trabajan estructuras como `ArrayList`, `HashSet` y `HashMap`, así como iteradores, criterios de ordenación, gestión de archivos y organización del código mediante clases con responsabilidades diferenciadas.

## 📌 Ejercicios

### Nivel 1

**Ejercicio 1 - Java Collections: Duplicados**

Uso de `ArrayList` y `HashSet` para comprender las diferencias entre ambas colecciones y la gestión de elementos duplicados mediante `equals()` y `hashCode()`.

[📖 Ver README](./Nivel1/exercise1/README.md)

**Ejercicio 2 - ListIterator: Recorrido inverso**

Uso de `ListIterator` para recorrer una lista de números enteros en orden inverso y almacenar sus elementos en una segunda lista.

[📖 Ver README](./Nivel1/exercise2/README.md)

**Ejercicio 3 - Java Collections: Capital Game**

Desarrollo de un juego de preguntas sobre capitales del mundo utilizando `HashMap`, selección aleatoria de elementos y lectura y escritura de archivos para almacenar las puntuaciones.

[📖 Ver README](./Nivel1/exercise3/README.md)

### Nivel 2

**Ejercicios 1 y 2 - HashSet y ordenación de restaurantes**

Gestión de restaurantes mediante `HashSet` para evitar duplicados exactos y utilización de `Comparable` para definir criterios de ordenación por nombre y puntuación. También se trabaja con Streams para obtener listas ordenadas.

[📖 Ver README](./Nivel2/exercice1and2/README.md)

### Nivel 3

**Ejercicio 1 - Gestor de personas y ordenación**

Desarrollo de una aplicación para gestionar personas a partir de un archivo CSV. Se trabaja con `ArrayList`, `Comparator`, expresiones lambda y diferentes criterios de ordenación, aplicando separación de responsabilidades entre clases.

[📖 Ver README](./Nivel3/README.md)

## 🛠️ Tecnologías y conceptos trabajados

- **Java:** programación orientada a objetos.
- **Collections Framework:** `ArrayList`, `HashSet` y `HashMap`.
- **Iteradores:** `Iterator` y `ListIterator`.
- **Gestión de duplicados:** `equals()` y `hashCode()`.
- **Ordenación:** `Comparable`, `Comparator` y `reversed()`.
- **Streams:** procesamiento y ordenación de colecciones.
- **Expresiones lambda:** definición de criterios de comparación.
- **Gestión de archivos:** lectura y escritura mediante `BufferedReader`, `BufferedWriter` y `FileReader`.
- **Gestión de excepciones:** control de errores durante las operaciones con archivos.
